# Archived Grinta v1.0.0 Manual Release Actions

This document is the archived pre-release checklist for `v1.0.0`. The stable release and PyPI package are now published; this file must not be used to infer current release readiness.

For later releases, use [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md). Repository history cleanup remains a separate maintainer operation because removing files from the current tree does not remove large blobs from existing Git history. Coordinate any history rewrite, back up refs, notify contributors, and require fresh clones afterward.
